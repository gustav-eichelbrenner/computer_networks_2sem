Например:

```
Интернет
    ↓
203.0.113.10:8080       ← внешний адрес
    ↓
   роутер
    ↓
192.168.1.10:80          ← внутренний сервер
```

Ты на роутере создаёшь правило:

```
203.0.113.10:8080 → 192.168.1.10:80
```
это правило в NAT и есть проброс порта

После этого человек **снаружи** может обратиться к:

```
http://203.0.113.10:8080
```

и попасть на веб-сервис, работающий на:

```
192.168.1.10:80
```
