# Настройка OpenVPN-L3-SRV

```bash
apt-get install openvpn easy-rsa
```

У Садыкова старая версия Easy-RSA 2.x, у нас скачивается Easy-RSA 3.x, поэтому ничего не трогаем, только раскомментить:

```bash
make-cadir ~/openvpn-ca
cd ~/openvpn-ca
nano vars
```
![[Pasted image 20261007133347.png]]
KEY_NAME в версии 3.x можно пропустить, потому что не нужны

`source vars` вводить не надо, `clean-all` тоже, да и вообще они запрещены. `./build-ca` тоже в 3 версии easy-rsa запрещен и вводить его не надо
Вместо них надо вводить:
```bash
./easyrsa init-pki
./easyrsa build-ca
./easyrsa build-server-full server nopass
./easyrsa build-client-full client1 nopass (потом надо будет перенести клиенту `ca.crt`, `client1.crt`, `client1.key`)
./easyrsa gen-dh
```
